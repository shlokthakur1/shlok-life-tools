Sync with GitHub

Your list is the file in your GitHub repo. Anyone can view it there, but editing needs a token. To edit from this browser, create a token once:

  1. Open GitHub → new fine-grained token.
  2. Under Repository access, choose Only select repositories → .
  3. Check Permissions → Contents is Read and write, then generate it and paste it below.
