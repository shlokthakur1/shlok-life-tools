Sync with GitHub

This checklist is the file data/dubai.md in your GitHub repo. Anyone can view it there, but editing needs a token. It's the same token as the To-do tab, so connecting here connects both.

  1. Open GitHub → new fine-grained token.
  2. Under Repository access, choose Only select repositories → shlok-life-tools.
  3. Check Permissions → Contents is Read and write, then generate it and paste it below.

The token is saved only in this browser on this device.
